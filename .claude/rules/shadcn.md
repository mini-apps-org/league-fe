# shadcn/ui Rules

These override the shared rules in `~/.claude/rules` where they conflict.

Style is `radix-nova` on Tailwind 4, with no `tailwind.config.ts`. Tokens live in `src/index.css`.

## Ownership

- `src/components/ui/` is generated by the CLI, then customised: the design's variants
  (button `touch` / `cta` / `icon-touch`, badge `tone`, alert `warn`) and its tokens live in the
  primitives. Re-running `add` on an existing component overwrites them, so diff and re-apply.
- One-off layout still belongs at the call site in `className`.
- Check before adding: `pnpm dlx shadcn info`, `pnpm dlx shadcn docs <component>`.
- Add through the CLI (`pnpm dlx shadcn add <component>`), never by pasting source.
- Review the diff after `add`: the CLI generates class strings against its own defaults.

## Composition

- Compose an existing primitive before hand-rolling one.
- Panels are `Drawer` from `components/ui/drawer.tsx` (vaul). Confirmations are drawers too, never
  `window.confirm`.
- Variants live in `cva` at the primitive. One-off layout belongs in `className`.
- Merge classes with `cn`, so consumer overrides win. Do not concatenate class strings.

## Styling

- `[lint]` No hex colours in class strings. Use the semantic tokens (`bg-card`, `bg-sunken`,
  `text-foreground`, `text-text-2`, `border-line`, `bg-primary`, `text-warn`). If no token fits, add one to `src/index.css` for both themes.
- Tailwind utilities over inline `style`. Safe-area padding works as an arbitrary value:
  `pb-[max(1rem,env(safe-area-inset-bottom))]`.
- Touch targets: `size="touch"` (48px) for ordinary actions, `size="cta"` (56px) for the one
  accent action per screen, `size="icon-touch"` (48px) for icon buttons. The Nova defaults stay
  32–36px for dense chrome.
- Hover styles stay behind `@media (hover: hover)`, which Tailwind 4's `hover:` already does.
- Icons come through `src/lib/icons.ts`. No emoji in the UI.
